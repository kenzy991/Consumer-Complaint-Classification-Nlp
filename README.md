# Consumer Complaint Classification

## Project Overview

Consumer Complaint Classification is an NLP and Deep Learning project that aims to automatically classify customer complaints into their corresponding product categories based on the complaint text (narrative).

The project uses Natural Language Processing (NLP) techniques and deep learning models to analyze customer complaints and predict the most appropriate category, helping improve complaint routing efficiency, reduce manual effort, and minimize operational costs.

## Project Objectives

- Build an end-to-end NLP text classification pipeline.
- Perform text preprocessing and exploratory data analysis.
- Develop and compare three recurrent neural network architectures: SimpleRNN, LSTM, and GRU.
- Fine-tune a pretrained Transformer model using Hugging Face.
- Evaluate and compare all four models using standard classification metrics.
- Deploy the best-performing model using Gradio to provide an interactive complaint classification interface.
